# Synthetic demonstration

All data here were generated by the seed simulator. They are not astronomical observations or evidence for memory in any real star.

Forecast scores use true, complete event histories, not the sampled photometry. The photometry and oracle visibility files separately illustrate gaps in observation. M2/M3 and inference with missed events are not implemented.

Run parameters, environment and CSV checksums are in `summary.json`. A fitted duration slope in the `latent` scenario can arise with zero direct duration effect.
