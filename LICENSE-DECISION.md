# Licence decision pending

No public software or documentation licence has been selected for the research
project. The seed is supplied for the user's research and further development.
Before a public release, the scientific lead should choose the code licence,
the documentation/manuscript licence, and the release boundary for data.

Possible choices include an OSI-approved software licence and a separate
Creative Commons documentation licence. These are options, not decisions made
on the user's behalf. Third-party observations and papers retain their own
terms. Do not infer a redistribution right from an archive's public web access.

No full-text third-party papers or real observations are bundled. The bibliography,
source links, original project notes and clearly labelled synthetic data are
provided to support follow-up research. Confirm institutional authorship, data
and release arrangements before dissemination.
