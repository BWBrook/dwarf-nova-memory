# Suggested first task for Claude: scientific and data-design audit

You are joining `dwarf-nova-memory`, a research project led by Barry W. Brook.
Read AGENTS.md and the start-here documents. The included code is deliberately
an oracle synthetic demonstration; no real astronomical result exists yet.

Your first deliverable is a critical but constructive **feasibility and novelty
memo**, not a manuscript. Work on a task branch and claim the task in the board.

1. Independently read the nearest historical recurrence studies, especially the
   2002 Ak et al. analysis and the SS Cyg work. Check the initial review against
   the sources. Follow citations and search recent forecasting/state-change
   papers through the current date. Record search queries and access depth.
2. State the specific additional claim the proposed evaluation could support.
   Distinguish prediction of ordinary recurrence from superoutburst precursors,
   descriptive correlations and physical causation. Report novelty overlaps.
3. Audit the proposed sample and event definitions. Which targets need exclusion,
   stratification or specialist advice? Do not infer current classification from
   a familiar name or treat a catalogue summary as a full event history.
4. Challenge the duration–gap definition, shared endpoint errors, observation
   policy, end-confirmation delay and validation protocol. Propose the smallest
   viable first analysis, with a testable failure condition.
5. Coordinate with the data-acquisition agent and independently annotate a small
   development interval after authentic data are available. Preserve differences
   rather than silently resolving every ambiguity in favour of the model.

Save the memo under `docs/audits/` with citations, concrete recommendations and
unresolved questions. Update the decision log only for decisions actually made.
Do not download a large archive, contact people, inspect locked future data or
write a results section before the first feasibility gate has been considered.
