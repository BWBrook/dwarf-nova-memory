# Agent prompts

Start each agent with `AGENTS.md` and the repository root. Then give Claude
`claude-kickoff.md` and Codex `codex-kickoff.md`, or swap them. The division is
convenience, not a claim about which model should own science or code.

Use `independent-review.md` for a defined milestone. Use `session-handoff.md` to
retain decisions and evidence across context limits. Avoid handing both agents
an open-ended instruction to “finish the paper”; begin with the first acceptance
criteria in the roadmap.
