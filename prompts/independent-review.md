# Independent milestone review

Review the specified commit and scientific claim as if you wanted to build on
the work. Be direct, fair and concrete. Read the relevant primary sources and
inspect the actual code/data evidence. Distinguish confirmed defects, plausible
risks, design alternatives and unresolved access limits.

Reproduce one critical calculation independently. Try a synthetic example that
produces the claimed pattern under a competing explanation. Prioritise:

- Forecast inputs that accidentally use future information, including other
  stars' later observations through pooled hyperparameters.
- Onset-duration coupling and shared uncertain end boundaries.
- Dropped long waits, unrecognised missed events and adaptive observing effort.
- Incorrect time/passband/upper-limit conventions or duplicated observations.
- Confounding of a shared activity state with a direct mark effect.
- Apparent sample size based on photometric points rather than systems/cycles.
- A comparison that changes state flexibility or observation likelihood between
  models while attributing the gain to the completed-outburst mark.
- Claims of absence or universality that exceed power or target population.

For every substantive finding, state severity, evidence, scientific impact,
minimal reproduction and a practical correction. Confirm what is sound as well.
Finish with an explicit view of which claim the current work supports and what
evidence would be needed for the next stronger claim. Do not edit the reviewed
implementation during an independent review unless that is separately agreed.
