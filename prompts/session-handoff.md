# Session handoff template

## Task and state

Task ID, branch/worktree, commit, modified files and whether the tree is clean.

## What changed and why

Scientific assumption or implementation; alternatives considered; decision-log ID.

## Evidence

Sources actually read, access depth, data/provenance IDs, commands run, outputs,
diagnostics and meaningful failures. Distinguish observed results from expectations.

## Validation boundary

Development or held-out inputs seen; information available at each forecast;
which tests are implementation checks and which evaluate scientific adequacy.

## Remaining uncertainty and next task

The smallest useful next action, acceptance criterion, files owned, dependencies
and any decision that genuinely needs the scientific lead. Do not restate the
entire repository or leave an unranked list of speculative enhancements.
